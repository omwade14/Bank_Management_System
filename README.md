# Bank Management System

**Developed by:** Om Wade

## Project Description
The Bank Management System is a Python-based application that manages basic banking operations. It uses Excel files to store account information.

## Technologies Used
- Python
- OpenPyXL
- Excel

## Features
- Create a new bank account.
- Check account balance.
- Deposit money.
- Withdraw money.
- Display account details.
- Store account records in an Excel file.

## Project Files
- `bank_management.py` – Main Python program
- `bank.xlsx` – Excel file generated to store account data when the program runs.

## Installation
Install the required library using:

```bash
pip install openpyxl
```

## How to Run
Run the following command in the terminal:

```bash
python bank_management.py
```

## Conclusion
This project demonstrates basic banking operations using Python and Excel file handling.
